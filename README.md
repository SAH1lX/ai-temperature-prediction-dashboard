# 🌡️ AI Temperature Prediction Dashboard

A modern machine learning powered weather dashboard that predicts afternoon temperature based on real weather conditions.

## 🚀 Features

- AI-based temperature prediction
- Interactive weather controls
- Real-time prediction updates
- Modern responsive dashboard UI
- Machine learning integration
- Data visualization

## 🛠️ Tech Stack

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Machine Learning

## 📊 Model Details

The project uses a trained Linear Regression model to predict afternoon temperatures based on:

- Humidity
- Pressure
- Wind Speed
- Morning Temperature

## 🎨 UI Features

- Glassmorphism inspired interface
- Dark futuristic theme
- Interactive sliders
- Responsive layout
- Real-time prediction cards
